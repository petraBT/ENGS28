A busy-waiting loop like for (int i=0; i<100000; i++); is fragile: the actual delay depends on compiler optimisation level and clock speed. The course library provides delay_ms(uint32_t ms), which busy-waits for a calibrated number of milliseconds. Always use #include "ES28.h" (rather than stm32C0xx.h directly) to get access to it.
