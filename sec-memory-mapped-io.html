    Section 1.4 Memory-Mapped I/O

    How does writing a number in C actually change a voltage on a pin? The key is memory-mapped I/O: peripheral registers live at fixed addresses in the same address space as RAM and flash. When the processor writes to address 0x50000014 (the address of GPIOA->ODR), the GPIO hardware captures the value and immediately changes the pin voltages.
    🔗
    The path from C code to pin voltage:
    🔗
    1. The C compiler translates the assignment into ARM machine instructions (load, OR, store).
      🔗
    2. The processor fetches and executes those instructions.
      🔗
    3. The store puts the new value on the data bus and asserts the GPIO address.
      🔗
    4. The GPIO peripheral latches the data into its ODR register.
      🔗
    5. Internal transistors respond and drive the pin HIGH or LOW.
      🔗
